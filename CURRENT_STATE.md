# Текущее состояние проекта

Обновлено: 2026-09-13 (v0.2.0 + Track F: фронтенд вокруг цели). История версий — [`CHANGELOG.md`](CHANGELOG.md), план и статус треков — [`docs/plan-caos-0.2.md`](docs/plan-caos-0.2.md).

## Что работает сейчас

- **Аутентификация**: email + верификация (токены с TTL, хеши в БД), OAuth Google/Stepik с серверными сессиями, ротация и отзыв refresh-токенов, отзыв сессий при смене пароля.
- **Домен 0.2**: граф целей (типизированные рёбра, impact-анализ), жизненный цикл цели с коллективным признанием, участие с контекстными ролями, обязательства, измеримые критерии, результаты с доказательствами и верификацией, решения как процесс (версии предложений, 4 метода, челленджи), связи проектов и знаний с графом.
- **Права**: доступ (access.py) отделён от возможностей (permissions.py): 8 capabilities по ролям в цели.
- **AI**: read-only ретривал в рамках прав пользователя; каждое предложение записывается и проходит человеческое ревью.
- **Инфраструктура**: Alembic (7 миграций, конвергентный baseline), CI (102 теста + smoke миграций + сборка фронтенда), деплой только после зелёного CI с бэкапом перед миграцией.
- **Прод**: https://caos.thinkred.ru (фронтенд), https://api-caos.thinkred.ru (API).

## Известные долги

- **Публичный фронтенд отстаёт**: DNS `caos.thinkred.ru` указывает на TimeWeb, где осталась старая сборка (FTP-путь деплоя удалён — креды скомпрометированы). Новый фронтенд уже обслуживается контейнером на VPS (`http://100.111.215.18:5173`, также по Tailscale); чтобы публичный домен показывал его, переведите DNS-запись `caos.thinkred.ru` на VPS (как у `api-caos`) — либо обновите FTP-секреты и верните lftp-шаг.
- Секции teams/competences/audit монолита разобраны не полностью (команды намеренно заморожены по ADR-0004).
- Легаси-таблицы `teams`/`team_members`/`project_members` заморожены, но существуют (переходный период по плану).
- Секреты из истории git не отозваны — ротация на владельце (`docs/security/secret-cleanup.md`).
- `owner_id` у цели сохраняется как legacy-поле; власть уже у матрицы прав, поле чистится в H-этапе.
- VPS: backend публикует порт 8000 наружу в обход хост-nginx TLS (`0.0.0.0:8000`) — закрыть publish на `127.0.0.1:8000:8000` при следующем проходе по инфраструктуре.
